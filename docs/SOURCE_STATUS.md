# 수집 소스 현황과 못 하는 이유

리포트 부록의 `소스 정상 N / 실패 N / 미설정 N` 이 무슨 뜻인지, 못 하는 곳은 왜
못 하는지 적어 둔다. 같은 곳을 다시 파지 않기 위한 문서다.

기준: 2026-09-27 수집. 전체 88개 소스 중 **활성 39 / 비활성 49**.

## 상태 낱말

| 낱말 | 뜻 |
|---|---|
| `정상` | 목록을 읽었다 |
| `0건` | 목록은 읽었는데 기간·키워드에 걸리는 글이 없다. 정상이다 |
| `실패` | 목록을 못 읽었다(차단·시간초과) |
| `미설정` | 게시판 주소나 셀렉터가 아직 안 정해졌다 |

`0건` 을 실패로 읽지 말 것. 게시가 뜸한 게시판은 대부분의 날에 0건이다.

## 못 하는 곳 — 네 갈래

### ① GitHub 러너 IP 차단 — 11곳

경남도청 · 진주시 · 거제시 · 의령군 · 함안군 · 창녕군 · 고성군 · 남해군 ·
산청군 · 함양군 · 합천군

**우리 코드 문제가 아니다.** 브라우저형 헤더·Referer·재시도를 붙이고 3개 러너
지역(westus3 ×2, centralus)에서 다시 돌렸는데 전부 같은 실패였다. 고성군은
`400 Request Blocked`(WAF)라 UA 가 아니라 IP 기준 차단인 것까지 특정됐다.

→ **국내 IP 에서 돌리면 열릴 가능성이 높다.** [LOCAL_RUN.md](LOCAL_RUN.md) 참고.

### ② API 키가 없다 — 2곳

| 소스 | 필요한 것 | 받는 곳 |
|---|---|---|
| `gojobs` 인사혁신처 공공기관 채용정보 | `DATA_GO_KR_KEY` | data.go.kr 에서 활용신청 |
| `work24` 고용24(구 워크넷) | `WORKNET_API_KEY` | work24 Open API 신청 |

`gojobs` 는 지금 `HTTP 403` 으로 **실패**로 잡힌다. 미설정이 아니라 키가 없어
거부당하는 것이다. 키를 저장소 Secrets 에 넣으면 바로 돈다.

발급에 본인 인증이 필요해 사람이 직접 해야 한다.

### ③ 아직 판단이 안 끝난 곳 — 4곳

| 소스 | 남은 질문 |
|---|---|
| `alio` 잡알리오 | `gojobs` 와 겹치는가. gojobs 가 403 이라 아직 비교를 못 했다 |
| `cleaneye` 클린아이 잡플러스 | 지방공기업·출자출연기관. API 유무 미확인 |
| `kosha_gn` 산업안전보건공단 경남 | 안전교육 강사 공고가 실제로 올라오는지 |
| `gn_cultural_centers` 시군 문화원 18곳 | 묶음 항목. 사이트 있는 곳만 개별 등록해야 한다 |

①②가 풀리기 전에는 실익을 판단하기 어렵다. `gojobs` 키가 생기면 `alio` 중복
여부부터 가려진다.

### ④ 오락가락하는 곳

`하동군` · `거창군` 은 날에 따라 열렸다 막혔다 한다. 실제로 2026-09-23 에는
창원·통영·밀양이 실패였는데 09-27 에는 셋 다 정상이고, 대신 하동이 막혔다.

**그래서 이런 곳은 끄지 않는다.** 하루 실패했다고 비활성으로 돌리면 다음 날
열리는 곳을 잃는다. 실패는 기록만 하고 다음 수집에서 다시 시도한다.

#### 거창군 403 — 손댈 것이 없다 (2026-10-04 확인)

10-04 08:06 수집에서는 목록 7건으로 정상이었는데 26분 뒤 08:32 에는 403 이었다.
같은 날 probe 로 세 가지를 확인했다.

- **UA 문제가 아니다.** Chrome UA·Referer·브라우저 헤더 전부를 붙여도 403 이다.
  고성군과 같은 IP 기준 차단이다. 헤더를 고치는 수는 기각한다
- **새올이 대안은 되지만 실익이 없다.** `eminwon.geochang.go.kr` 은 열린다(HTTP 200,
  고시공고 51행). 그러나 고시공고 게시판이라 강사 공고가 없다. `geochang_eminwon` 으로
  설정만 남겨 두고 끈 채로 둔다
- **막혀도 잃는 것이 없다.** 거창 홈페이지 게시판은 9~10월 저장 0건이다. 목록에는 떴지만
  민간 구인글이라 분류기가 전부 걸렀다(제외 목록에 10건)

따라서 거창 403 이 다시 나도 조치하지 않는다. 기록만 남긴다.

## 숫자를 읽을 때

리포트의 집계는 **마지막 수집 실행** 기준이다. 수집이 며칠 밀렸으면 그만큼 낡은
숫자다. 실제로 09-27 리포트가 한동안 09-23 실행의 `실패 4 / 미설정 18` 을 그대로
보여주고 있었다. 숫자가 이상하면 `python -m gia status` 로 마지막 수집 시각부터
확인할 것.

## 첨부를 못 읽는 곳

### 경남교육청 구인구직포털(`gne`) — 미해결

학교 공고는 본문이 서너 줄이고 알맹이(수업 일정·자격·서류)가 HWP 첨부에 있다.
그런데 이 포털은 첨부 주소를 주지 않는다. 2026-09-29 러너에서 확인한 것:

- 목록 링크는 `<a class="file" href="javascript:fnKfileDownload('<uuid>')">`.
  그 함수는 주소를 만들지 않고 RAON 업로드 컴포넌트를 띄울 뿐이다
- 페이지 스크립트의 `fileData[uuid].fileAddr` 에 실제 경로가 있다
  (`upload/raonkupload/2026/09/21/<hash>.hwp`). 그 경로로 바로 받으면 **404**
- 미리보기(`/user/bbs/ND_filePreview.do?q_fileSn=…&q_fileId=…`)는 200 이지만
  Synap 문서뷰어(`/synap/skin/doc.html?fn=…&rs=…`)로 넘기는 빈 껍데기다.
  변환 결과 경로는 뷰어 JS 번들이 실행 중에 만든다. `.html`·`/index.html`·
  `.files/index.html`·`.txt` 네 가지를 시도했고 전부 404

→ **브라우저로도 못 읽는다. 2026-09-29 에 실제로 해 보고 접었다.**

Playwright 로 상세 페이지를 열어 `a.file` 을 눌러 보는 방식을 만들어 러너에서 세 번
돌렸다. 두 가지 길을 다 뒀다 — 브라우저의 내려받기 사건을 기다리는 길과, 오가는 응답
가운데 파일로 보이는 것(Content-Disposition 이 attachment 이거나 본문 형식이 문서)을
가로채는 길. 결과는 둘 다 빈손이었다:

```
[gne] 브라우저 첨부 …regSn=1814620: 받은 글 0개 · 첨부 1: 파일 응답이 오지 않음
      | [진단 #component_holder]        ← 비어 있음
[gne] 브라우저 첨부 …regSn=1814618: 페이지 열기 실패: net::ERR_EMPTY_RESPONSE
```

- 셀렉터는 맞다. 링크를 찾았다("첨부 1")
- 눌러도 `#component_holder` 가 **비어 있다**. RAON 컴포넌트가 아예 뜨지 않는다.
  컴포넌트가 없으니 그 안의 XHR 도 없고, 가로챌 응답도 없다
- 한 건은 서버가 브라우저 요청을 끊었다(`ERR_EMPTY_RESPONSE`). 러너에서 오는
  헤드리스 브라우저를 서버가 거르는 것으로 보인다

값도 비쌌다 — 공고 하나당 약 30초(링크마다 응답을 기다린다), 러너마다 크로미움
190MB 내려받기. 얻는 것이 0이므로 코드를 되돌렸다.

다시 해 보려면 이것부터 확인할 것: 헤드리스가 아닌 창으로 띄웠을 때 컴포넌트가 뜨는지,
평범한 브라우저로 먼저 목록을 거쳐 들어가면 달라지는지. **국내 IP 의 진짜 브라우저에서는
될 가능성이 있다**(docs/LOCAL_RUN.md). 컴포넌트가 뜨는 것을 먼저 눈으로 확인하기 전에는
자동화를 다시 짜지 말 것 — 위 세 번이 그것을 확인하지 않고 시작해서 헛돌았다.

그 전까지 경남교육청 공고는 강사잇다 양식에서 수업 일정이 빈 `보류` 줄로 남는다 —
원문 링크로 확인해 손으로 채우면 된다.

### 통영국제음악재단(`timf`) — 첨부는 안 읽는다, 그게 맞다

이 공고는 본문이 인사말 몇 줄뿐이고 모집 내용이 첨부 PDF 에 있다. 그런데 첨부
주소(`https://timf.org/site/download.asp?…`)는 **이 사이트 robots.txt 가 막은
경로**다. 2026-09-29 러너 확인:

```
[detail] 첨부 추출 실패: ['robots.txt 차단: https://timf.org/site/download.asp?…']
```

`collector.respect_robots: true` 가 이것을 거른다. **고칠 것이 아니다** — 사이트가
가져가지 말라고 한 경로다. 이 공고는 강사잇다 양식에서 수업 일정이 빈 `보류` 줄로
남고, 원문 링크로 확인해 손으로 채운다.

(한때 파일 이름을 못 읽어서 실패하는 것으로 보였다. 주소가 `download.asp?file=
공고문%2Epdf` 꼴이라 경로만 보면 확장자가 `.asp` 였기 때문이다. 그 이름 인식은
따로 고쳐 두었지만, 이 소스의 실패 원인은 그게 아니라 robots.txt 였다.)

## 고친 것

- **양산시**: 목록 링크가 `req.post(this)` 라 상세 주소를 못 만들었는데, 앵커의
  `data-action` 속성에 상세 GET 주소가 통째로 들어 있었다. `link_attr: data-action`
  으로 해결(2026-09-27). 구조 덤프가 속성값을 40자에서 자르는 바람에 주소가
  파라미터 이름에서 끊겨 없는 것처럼 보였던 게 오래 막혀 있던 이유다.
- **첨부 읽기 세 가지**(2026-09-29): HWP 의 사용자 지정 영역 글머리 기호(U+E000~
  U+F8FF)를 글머리로 인정, 확장자가 물음표 뒤에만 있는 주소(`download.asp?file=
  …%2Epdf`)에서 파일 이름 찾기, 빈 응시원서보다 공고문을 먼저 읽기. 김해시
  진영한빛도서관 건의 수업 일정이 이걸로 채워졌다.
